# 欧洲单节点上线执行清单

> 目标架构：一台欧洲 VPS（推荐法兰克福）跑全套 docker compose，全球访客经 Cloudflare CDN 访问，管理员从国内经 VPN/HTTPS 管理。
> 前置：代码已在 GitHub（master 最新），域名购买中。

---

## 阶段 1：服务器采购与初始化（约 30 分钟）

- [ ] 购买 VPS：**法兰克福 / 2C4G / 40G+ SSD / Ubuntu 22.04**（阿里云国际、腾讯云国际、UCloud 或 Hetzner）
- [ ] 创建非 root 用户、配置 SSH 密钥登录、禁用密码登录
- [ ] 安装 Docker：`curl -fsSL https://get.docker.com | bash`，并把当前用户加入 docker 组
- [ ] 防火墙：只放行 22（限你的 IP 或 VPN 出口）、80、443
- [ ] （可选）配置 fail2ban

## 阶段 2：域名与 DNS（购买域名后）

- [ ] 域名 DNS 托管到 **Cloudflare**（免费版，改 NS 记录到 Cloudflare 分配的两个 NS）
- [ ] Cloudflare 添加 A 记录（全部指向服务器 IP，先开"仅 DNS"灰云，配置好后再开橙云代理）：
  - `@` / `www` → portal
  - `admin` → 管理后台
  - `api` → API
- [ ] Cloudflare SSL/TLS 模式选 **Full (Strict)**，用 Origin CA 证书（Cloudflare → SSL/TLS → Origin Server → Create Certificate，15 年有效，免费）下载 pem/key

## 阶段 3：代码与环境配置

- [ ] 服务器上 `git clone` 仓库
- [ ] `cp .env.example .env`，按下表填写：

| 变量 | 值 |
|---|---|
| `POSTGRES_PASSWORD` / `REDIS_PASSWORD` / `MINIO_ROOT_PASSWORD` / `MINIO_SECRET_KEY` | 强随机密码（`openssl rand -hex 16`） |
| `JWT_SECRET` | **必填**，`openssl rand -hex 32` |
| `DEEPSEEK_API_KEY` | DeepSeek 控制台申请 |
| `NEXT_PUBLIC_API_URL` | `https://api.<你的域名>` |
| `NEXT_PUBLIC_PORTAL_URL` | `https://<你的域名>` |
| `CORS_ORIGINS` | `https://<你的域名>,https://www.<你的域名>,https://admin.<你的域名>` |
| `MINIO_PUBLIC_URL` | `https://api.<你的域名>/files`（或对象存储公网地址） |
| `SEED_ADMIN_PASSWORD` | 强密码（仅首次 seed 用） |

- [ ] 把 Origin CA 证书放到 `docker/ssl/`（`hiwhale.com.pem` / `hiwhale.com.key`，文件名按 nginx.conf 注释块里的约定，或改成你的域名）

## 阶段 4：HTTPS 启用（域名确定后）

- [ ] `docker/nginx.conf`：取消末尾 HTTPS 注释块，注释掉三个 listen 80 的 server 块；80 只留 301 跳转
- [ ] `docker-compose.yml` nginx 服务：开放 `443:443`，挂载 `./docker/ssl:/etc/nginx/ssl:ro`
- [ ] 三个 server 块的 `server_name` 把 hiwhale.com 替换为真实域名（全局替换即可）

## 阶段 5：部署与初始化

- [ ] `bash deploy.sh`（自动：构建 → 迁移 → MinIO 初始化 → 健康检查）
- [ ] 创建超管：`DATABASE_URL=postgresql://<用户>:<密码>@<服务器IP>:5432/hiwhale SEED_ADMIN_PASSWORD=<强密码> pnpm --filter @hiwhale/api db:seed`（在能连到服务器的本机执行；或服务器上临时开端口执行后关闭）
- [ ] 验证：
  - [ ] `https://<域名>` 门户打开，星空首页正常
  - [ ] `https://admin.<域名>` 登录成功，**立即修改超管密码**
  - [ ] `https://api.<域名>/health` 返回 ok
  - [ ] 后台上传一张素材图，前台对应位置显示
  - [ ] 提交一条测试询盘，后台可见（测完删除）
  - [ ] AI 客服对话正常（DeepSeek）

## 阶段 6：内容替换（上线前最后一步）

- [ ] admin 案例管理：6 个虚构案例替换为真实内容（或删除）
- [ ] admin 内容管理：数据指标 / 公司介绍 / 联系方式填真实数据
- [ ] admin 知识库 → FAQ 管理：CSV 批量导入行业常见问题（AI 客服即以此回答）
- [ ] 认证清单核对（无 UL 证书则移除 UL）
- [ ] 隐私政策补充数据存储地声明（欧盟客户）

## 阶段 7：加固与运维

- [ ] Cloudflare 橙云代理打开（CDN 生效）
- [ ] admin 子域加 Cloudflare WAF 规则：仅允许你的出口 IP/VPN 段访问（免费版支持 IP 规则）
- [ ] 备份：`backups/` 已有轮转（7 份）；建议每周 `scp` 一份到国内
- [ ] 监控：Cloudflare 自带可用性监控（免费版可配邮件告警）
