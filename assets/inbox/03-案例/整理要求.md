# 案例素材整理要求

> 每整理一个真实客户案例 = 1 份文字模板（复制 `案例模板.md` 填写）+ 现场图 + 客户 Logo（可选）。
> 文字只需填中文。图片放入本目录（`assets/inbox/03-案例/`）。

## 一、文字内容

| 字段     | 必填 | 说明                                              |
| -------- | ---- | ------------------------------------------------- |
| 客户名称 | ✅   | 对外展示名（保密需要可用化名，如"某头部电商企业") |
| 所属行业 | ✅   | 电商 / 汽车 / 第三方物流 / 食品冷链 / 医药 / 港口 |
| 项目名称 | ✅   | 如"华南履约中心智能化改造"                        |
| 客户背景 | ✅   | 2-3 句（客户是谁、业务规模）                      |
| 面临挑战 | ✅   | 3-4 句（改造前的痛点）                            |
| 解决方案 | ✅   | 3-5 句（我们交付了什么）                          |
| 设备清单 | ✅   | 逐条列出（如"MBV15R 无人叉车 × 12 台")            |
| 实施周期 | ✅   | 如"14 周"                                         |
| 成果数据 | ✅   | 3-4 条"数值 + 指标"（最好有前后对比）             |
| 客户评价 | 选填 | 引用语 + 评价人姓名 + 职务（需客户授权）          |

## 二、图片素材

| 图片       | 文件名                                            | 比例 | 推荐像素        | 必填 |
| ---------- | ------------------------------------------------- | ---- | --------------- | ---- |
| 案例现场图 | `case-{客户英文名}.png`（如 case-globalecom.png） | 21:9 | 2100×900        | ✅   |
| 客户 Logo  | `case-logo-{客户英文名}.png`                      | 2:1  | 480×240，透明底 | 选填 |

⚠️ 客户保密：现场图不可含客户品牌/标识性元素。可用 AI 生图（`素材需求清单.md` 有现成提示词）或现场拍摄后脱敏处理。
