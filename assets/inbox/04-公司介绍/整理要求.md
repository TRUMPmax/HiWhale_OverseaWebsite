# 公司介绍素材整理要求

> 关于我们页面的全部真实信息 = 1 份 `公司介绍模板.md` + 图片素材。
> 文字只需填中文。图片放入本目录（`assets/inbox/04-公司介绍/`）。

## 一、文字内容（一个文件搞定）

| 板块     | 字段                                       | 必填                                   |
| -------- | ------------------------------------------ | -------------------------------------- |
| 使命     | 一句话使命陈述                             | ✅                                     |
| 定位     | 公司定位说明（2 段）                       | ✅（已按你提供的真实简介预填，可修改） |
| 发展历程 | 5-6 个里程碑：年份 + 事件                  | ✅（需要你提供真实大事记）             |
| 全球布局 | 基地/办公室列表（城市 + 角色）             | ✅（已按深圳/苏州/青岛预填）           |
| 研发实力 | 研发团队/专利/服务国家 三个数字 + 一段说明 | ✅                                     |
| 资质认证 | 认证清单（国家高新/专精特新/ISO 等）       | ✅（已按你提供的信息预填）             |
| 合作伙伴 | 合作方名称列表（6 个以内）                 | 选填                                   |
| 联系信息 | 邮箱/电话/地址/WhatsApp/LinkedIn           | ✅（已填真实信息）                     |

## 二、图片素材

| 图片          | 文件名                       | 比例 | 推荐像素       | 用途                           |
| ------------- | ---------------------------- | ---- | -------------- | ------------------------------ |
| 团队/办公场景 | about-team.png               | 4:3  | 1200×900       | 定位板块                       |
| 世界地图      | about-world-map.png          | 21:9 | 2100×900       | 全球布局（标注深圳/苏州/青岛） |
| 研发中心/工厂 | about-factory.png            | 16:9 | 1920×1080      | 研发实力                       |
| 合作伙伴 Logo | partner-logo-01.png ~ 06.png | 2:1  | 480×240 透明底 | 合作伙伴墙                     |
| 联系页地图    | contact-map.png              | 4:3  | 1200×900       | 联系页（建议高德地图截图）     |

⚠️ 办公室/工厂照片请脱敏（门牌、其他公司标识、员工正脸需授权）。
