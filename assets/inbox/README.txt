HiWhale 素材收件箱 / Asset Inbox
================================

用法：把准备好的素材按用途放进对应子目录，文件名与网页占位块上标注的"素材名"保持一致。
我会定期把这里的文件归类、压缩、复制到网站静态目录并替换占位块。

子目录说明：
  home/       首页素材（主视觉、三层能力示意图等）
  products/   产品图片（产品主图、缩略图，如 product-mbv15r.png）
  industries/ 行业场景图（industry-ecommerce.png 等）
  clients/    客户 Logo（client-logo-01.png 等，透明底 PNG 最佳）
  certs/      认证标志（cert-ce.png 等，透明底 PNG 最佳）
  videos/     视频（home-brand-video.mp4 等）
  models/     3D 模型（model-*.glb / .gltf）
  other/      其他素材

注意：
- 图片建议 WebP/PNG/JPG；比例参考占位块上标注的"建议尺寸"
- 文件名保持小写、用连字符，与占位块"素材名"完全一致
