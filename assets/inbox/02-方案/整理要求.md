# 方案素材整理要求

> 每整理一个真实行业方案 = 1 份文字模板（复制 `方案模板.md` 填写）+ 1 张场景图。
> 文字只需填中文。图片放入本目录（`assets/inbox/02-方案/`）。

## 一、文字内容

| 字段 | 必填 | 说明 |
|---|---|---|
| 方案标题 | ✅ | 如"电商履约自动化解决方案" |
| 所属行业 | ✅ | 电商 / 汽车 / 第三方物流 / 食品冷链 / 医药 / 港口（六选一；要加新行业请单独告诉我） |
| 方案简介 | ✅ | 列表卡片展示，40-60 字 |
| 方案详述 | ✅ | 详情页主体，150-300 字 |
| 行业痛点 | ✅ | 4 条，每条 ≤15 字（如"大促订单峰值") |
| 设备组合 | ✅ | 从产品品类中选 3-5 个（无人叉车/AMR/机械臂 等） |
| 部署流程 | ✅ | 5 个步骤，每步"步骤名 + 一句话说明"（如"现场勘测 - 工程师上门测绘场地") |
| 成果数据 | ✅ | 3-4 条"数值 + 指标名"（如"+180% 拣选效率") |

## 二、图片素材

| 图片 | 文件名 | 比例 | 推荐像素 |
|---|---|---|---|
| 方案场景图 | `solution-{行业英文}.png`（如 solution-ecommerce.png） | 16:9 | 1600×900 或 1920×1080 |

场景图要求：真实仓库/产线作业感，无人设备工作场景，无客户品牌标识（客户保密）——可参考 `素材需求清单.md` 里的生图提示词用 AI 生成。
