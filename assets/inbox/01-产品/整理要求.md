# 产品素材整理要求

> 每整理一个真实产品 = 1 份文字模板（复制 `产品模板.md` 填写）+ 图片素材。
> 图片放入本目录（`assets/inbox/01-产品/`），文件名按下方规范命名。
> **文字只需填中文，英文版我负责翻译。**

## 一、文字内容（必填/选填）

| 字段             | 必填 | 说明                                                                                                     |
| ---------------- | ---- | -------------------------------------------------------------------------------------------------------- |
| 产品名称（中文） | ✅   | 如"平衡重式无人叉车"                                                                                     |
| 型号             | ✅   | 如 MBV15R（真实型号请替换现有 mock 型号）                                                                |
| 所属品类         | ✅   | 从现有体系选：有人叉车 / 无人叉车 / RGV / AGV / AMR / 机械臂 / 龙门吊 / WCS 调度系统 / IWMS 仓储管理系统 |
| 一句话卖点       | ✅   | 列表卡片和详情页头部展示，≤30 字                                                                         |
| 产品描述         | ✅   | 80-150 字，详情页展示                                                                                    |
| 核心参数（速览） | ✅   | 3-4 条，"参数名: 数值 单位"，如"额定载重: 1,500 kg"                                                      |
| 详细参数表       | ✅   | 按分组（通用/性能/电池或动力/安全/通信/平台）每组 3-5 条                                                 |
| 产品卖点         | ✅   | 3-4 条，每条 ≤20 字                                                                                      |
| 适用行业         | ✅   | 从：电商 / 汽车 / 第三方物流 / 食品冷链 / 医药 / 港口 中选 2-3 个                                        |
| 新产品 slug      | 选填 | 英文小写连字符，如 `mbv15r-counterbalanced-agv-forklift`，不填我生成                                     |

## 二、图片素材

| 图片                 | 文件名                                            | 比例 | 推荐像素 | 必填 |
| -------------------- | ------------------------------------------------- | ---- | -------- | ---- |
| 产品主图             | `product-{型号小写}.png`（如 product-mbv15r.png） | 4:3  | 1200×900 | ✅   |
| 缩略图 1（侧面）     | `product-{型号小写}-thumb-1.png`                  | 1:1  | 600×600  | 选填 |
| 缩略图 2（作业状态） | `product-{型号小写}-thumb-2.png`                  | 1:1  | 600×600  | 选填 |
| 缩略图 3（细节特写） | `product-{型号小写}-thumb-3.png`                  | 1:1  | 600×600  | 选填 |
| 3D 模型              | `model-{slug}.glb`                                | —    | ≤10MB    | 选填 |
| 规格书 PDF           | `spec-{型号小写}.pdf`                             | —    | ≤20MB    | 选填 |

图片要求：白底或浅灰底、产品占画面 70% 以上、无水印、无其他品牌标识。
**软件类产品（WCS/IWMS）不需要产品照**，改为 3 张界面截图：`{slug}-ui-dashboard.png / -ui-orders.png / -ui-analytics.png`，16:9、1920×1080。
